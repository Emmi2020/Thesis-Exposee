\subsection{Test Bench Virtualization}

During the initial phase of the internship, a task was introduced to virtualize the \acp{OS} and software running on the test benches. Test benches are specialized setups used in production environments as well as in research and development to simulate, test, and validate the performance and behavior of product components under controlled conditions.

The virtualization project was necessary to address limitations of the physical \acp{PC}, which were aging along with their operating systems. A simple solution would have been to upgrade the hardware and operating systems. However, much of the software installed on these \acp{PC} had compatibility issues with newer operating systems because newer versions and updates were unavailable.

\subsubsection{Host PC Preparation}

For the implementation, several items were requested from the responsible \ac{IT} department to make the virtualization process possible. The requested items were:

\begin{itemize}
    \item HP \acp{PC}.
    \item VMware Workstation as the virtualization software.
    \item Acronis imaging software for creating and managing disk images.
    \item Two-port \acp{NIC} for providing connectivity to the \acp{VM}.
    \item Serial interface cards for connecting legacy devices.
\end{itemize}

Before the virtualization process could begin, the operating systems of the aging physical \acp{PC} were cloned using the Acronis imaging tool and saved in the \ac{VMDK} file format, which is compatible with VMware virtualization software. The image files were then transferred to the new host \acp{PC} through a network file share.

The next step was to prepare the new host \acp{PC} for virtualization by installing the serial interface cards, the two-port \acp{NIC}, and the VMware software. The network cards were configured to provide direct network connectivity to the \acp{VM}. One port was used to connect to the SPS, while the other was used to connect to the IMC.

Several settings were adjusted on the host \ac{PC} to optimize the performance and compatibility of the virtual machines. For example, the memory allocation, the \ac{BIOS} settings required to enable virtualization, and the network configurations for assigning static IP addresses were configured to ensure that the virtual machines ran smoothly and maintained reliable network connectivity.

\subsubsection{Installation and Setup of the VM}

The installation and setup of the virtual machine were carried out through the VMware interface. First, a new virtual machine was created. After proceeding through the setup wizard, the custom installation option was selected to configure virtual resources such as memory allocation, the number of processors, and disk space.

The \ac{VMDK} image file was then attached to the newly created virtual machine as its primary disk. This allowed the virtual machine to boot from the cloned operating system and access all the software and configurations that were present on the original physical \ac{PC}.

\subsection{Team SharePoint Document Management System}

\subsubsection{Introduction}

Managing a team requires an efficient way to collaborate and share information among team members. SharePoint is a powerful platform that facilitates document management, team collaboration, and information sharing, from large corporate environments to small teams. In many cases, information sharing expands and becomes more complex because of a lack of organizational standards and proper document management practices.

To address these challenges, the intern was assigned the task of improving the document management system and creating guidelines for document sharing within the team. The task involved setting up site libraries, creating a document management system, and establishing organizational standards for document sharing. It also included redesigning the team's SharePoint site. The guidelines aimed to provide clear instructions and best practices for document organization, version control, and access permissions, thereby ensuring efficient collaboration and information sharing within the team.

\subsubsection{Initial Situation and Objectives}

\paragraph{Problem}

The team's SharePoint site contained a pre-configured structure consisting of document libraries, lists, folders, and various site templates. However, the existing structure lacked clear organizational standards and proper document management practices, making it difficult for team members to collaborate and share information efficiently.

\paragraph{Objective}

The objective of the task was to improve the library structure by adding automated document management and search functionality through metadata tagging, content types, and custom views. These features made it easier for team members to locate and manage documents.
