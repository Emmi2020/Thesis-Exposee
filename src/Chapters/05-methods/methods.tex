\section{Methodology and Tools}

\begin{itemize}
    \item \textbf{Data Pipeline Engineering:} data cleaning scripts with pandas/openpyxl to handle Excel files will be used. Databricks as a platform is put into consideration for transforming SharePoint files into Databricks Unity Catalog for readable database tables.
    \item \textbf{Information Retrieval and Semantic Search:} dense vector embeddings will be used to transform textual failure data into high-dimensional vectors. Databricks Vector Search will rank semantic similarity to facilitate efficient retrieval of relevant historical D-FMEA entries.
    \item \textbf{Agentic Language Processing:} an agentic LLM\footnote{Large Language Models are categories of deep learning models trained on amounts of data.} will map retrieved context rows into the target D-FMEA template format.
    \item \textbf{Evaluation and Validation:} the performance of the AI-assisted D-FMEA creation will be assessed based on retrieval precision, process metrics like time completion compared to manual engineering workflows, and qualitative feedback on usability and risk visibility.
\end{itemize}
